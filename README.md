# Salcombe Deli demo — 给 SuiFei

这是一页给店老板看的门面站 demo，不是上线站，也不是报价单。文件在 `/workspace/demos/salcombe-deli/index.html`。用手机打开即可。

没有联系店家。没有自称程序员。页脚只有店名和 Salcombe。

都来自同目录 `source.md`（2026-08-27 搜集），页面上能对上的是：

- 店名：The Salcombe Delicatessen
- 地址：52 Fore Street, Salcombe, Devon TQ8 8JE
- 电话：01548 842332（`tel:+441548842332`）
- 邮箱：info@salcombedeli.co.uk（来自联系页）
- 时间：周一到周日 10.00am–4.00pm，周三休息；另写一句时间会改、请先打电话（菜单页原话：opening times alter monthly）
- 邮件订三明治 / 袋棍 / 沙拉要至少提前 24 小时；错过了就在营业时间打电话
- 蟹和虾卖得快，建议提前订第二天
- 面包：Granary 或 White；袋棍 White 或 Multigrain。现做三明治没有无麸质面包，柜上有 GF 点心——没编点心名字
- 三明治 20 种 + 儿童款，价格按他们三明治菜单页（三明治 / 袋棍）
- 沙拉四条按首页：Chicken Caesar £8.50、Greek £8.75、Classic £5.95、Crab £16.75
- Pasties：Steak / Beef & Stilton / Cheese & Onion £5.35；Vegan £5.50（问当天口味）
- 篮子三条及列出的内容：Little Sweet £22.99、Sweet Treats £34.99、Savoury £36.99
- 本地采购只写成「尽量从西南部进货」，生产者名字只出现在篮子名单里
- Maps 约 4.7 / 约 93 条，没有编顾客原话
- Instagram @thesalcombedeli（首页「Click here for our Instagram page」链过去的，不是猜的）

## 哪些是占位 / 故意没写

- **订货表单**：没有。按钮是打电话和发邮件，不会假装提交。
- **现站 salcombedeli.co.uk**：没有链成「我们的官网」。这页是替换草图。现站技术栈（WordPress 4.5 / 2016）只写在 `source.md`，不要念给老板听成攻击。
- **Pizza / Buffet / 即食餐、奶酪柜、冰淇淋、邮寄 pasties**：现站有，这页没放。
- **沙拉 Prawns £9.50、额外酱汁 £0.80**；篮子另外三款和礼券；Shop 表单里一套更旧的篮子价。
- **店主 / 主厨 / 开业年份**：About 没写清楚，没编。
- **具名点评**：没有。

## 建议怎么开口

先把手机递过去，让他自己往下划。不要先讲技术，不要说「我是做网站的」。

可以这样说：

> 网上搜你们店，会进到现在那一页。我按柜台上的三明治、沙拉、pasties 和价，做了一页给您看。订货还是打电话或发邮件，这页不会假装能下单。时间写的是你们现在站上的：十点到四点，周三休息——菜单上也写了时间会改，所以下面留了一句请先打电话。

等他看完，再问两件具体的：

1. 价格要不要换成这周柜台上的（这份是 8 月底网上那一版）。
2. Pizza、即食餐、邮寄篮子要不要也放上来，还是这页只做进店和订三明治。

他如果觉得不像，就收起来。这页的用处是让他先看见自己的店，不是说服他买网站。
